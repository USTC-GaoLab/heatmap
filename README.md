# Heatmap Analysis

## Overview

This repository contains scripts and resources for generating heatmaps in biological data analysis.

## Repository structure

- `R/` - reusable package-style R functions
- `examples/` - small, non-sensitive usage examples
- `docs/` - design and review documentation

Keep reusable functions in `R/` and analysis-specific demonstrations in
`examples/`. Do not commit source datasets or generated figures.

## Usage

Please document input matrix format, normalization method, and plotting parameters when adding new analyses.

## Reproducibility

Record software versions and package dependencies in `ENVIRONMENT.md`.
